## Examined and Decided Was Not a Defect
1. **PyMongo Synchronous Driver with FastAPI**:
   FastAPI automatically offloads standard synchronous route functions (`def` instead of `async def`) to an internal threadpool (`anyio.to_thread`), preventing event loop blockage during database I/O while maintaining simplicity and robust connection pooling.
2. **Absence of `_id` in Attendance & Employee Payloads**:
   The domain model addresses employees by natural key `emp_code` and attendance logs by compound key `(emp_code, date)`. Stripping `_id` and omitting auto-generated primary keys is an intentional requirement of the specification.
3. **Stored Derived Values Used in Analytics**:
   Analytics aggregations read stored derived values (`work_hours`, `late_minutes`, `overtime_minutes`, `half_day`) rather than dynamically calculating them from raw punch timestamps. This aligns directly with DATA_MODEL.md which specifies that stored derived values are authoritative.
